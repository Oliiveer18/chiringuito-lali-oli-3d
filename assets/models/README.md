# Modelos GLB (Tripo)

Modelos 3D generados con la API de Tripo, integrados mediante `assets-3d.js`.

Cada modelo se referencia con su ruta relativa desde la raíz del sitio:
- `coffee-machine.glb` — cafetera espresso profesional de la Estación 2
  (sustituye a la geometría procedural de `render-3d.js`).

Si un archivo no existe, el juego mantiene el respaldo procedural sin errores.
